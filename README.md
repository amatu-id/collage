# Kolase

Kolase foto di browser — bagian dari Portal AMATU (`amatu-id.github.io/collage`).

- 90+ tata letak (1–36 foto), bentuk bingkai (kotak, oval, lingkaran, lengkung, hati, heksagon, berlian, bintang), jarak, margin, sudut, garis, bayangan, latar.
- Bingkai kosong: klik **Unggah**, pilih bingkai lalu **Ctrl/⌘+V**, atau seret foto langsung ke bingkai.
- **Susun otomatis**: seret banyak foto → ditata memenuhi kertas (A4, F4, foto 4R, dll.) tanpa ruang kosong, otomatis beberapa halaman. Mode Otomatis / Baris rapi / Mosaik / Grid seragam, foto per halaman, boleh ubah urutan / putar 90°.
- Atur foto: geser, zoom, putar, cermin, luruskan, tukar posisi (seret), bagi bingkai, 13 filter + penyesuaian warna.
- Teks & stiker, kertas cetak dan ukuran digital (Instagram, Story, 16:9).
- Ekspor PDF (semua halaman) / JPG / PNG (ZIP), cetak langsung. Data tersimpan di IndexedDB `amatu-collage` (disinkronkan oleh `/amatu.js`).

Tanpa build: `index.html` + `css/app.css` + `js/*.js` (ES modules).
